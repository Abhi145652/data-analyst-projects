# Power BI – Sales Performance & Profitability Dashboard

An interactive Power BI dashboard developed to analyze sales performance, profitability, product categories, regions, countries, and customer-related trends.

## 📊 Dashboard Overview

This project contains multiple Power BI report pages:

- **Dashboard** – Overall sales, profit, cost and order quantity KPIs
- **Region-wise Sales** – Sales and profitability analysis across regions
- **Country-wise Destination** – Country-level and geographic sales analysis
- **Category-wise Sales** – Category and sub-category performance analysis

## 🔍 Key Analysis

- Sales Amount and Profit analysis
- Total Product Cost analysis
- Order Quantity tracking
- Profit Percentage analysis
- Region-wise sales performance
- Country-wise sales analysis
- Category and sub-category performance
- Sales trend analysis
- Geographic visualization
- Waterfall analysis
