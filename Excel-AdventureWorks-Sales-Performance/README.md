# Excel – AdventureWorks Sales & Business Performance Dashboard

An interactive Excel dashboard developed using the AdventureWorks dataset to analyze sales performance, profitability, production costs, customer performance, regional sales, product performance, and sales trends.

## 📊 Dashboard Overview

This project includes multiple Excel-based analysis sheets and an interactive dashboard covering:

- KPI Analysis
- Monthly Sales Analysis
- Year-wise Sales Analysis
- Quarter-wise Sales Analysis
- Region-wise Sales Performance
- Customer Performance
- Top 10 Products
- Sales vs Production Cost Analysis

## 🔍 Key Analysis

- Total Sales and Profit analysis
- Profit Margin analysis
- Production Cost analysis
- Monthly and yearly sales trends
- Quarterly sales performance
- Region-wise sales performance
- Customer performance analysis
- Top 10 product sales analysis
- Sales Amount vs Production Cost comparison
- Interactive filtering using slicers
